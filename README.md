# 西江水情与船闸待闸看板

每天看三样东西：**梧州水位、长洲/桂平/大藤峡 上下行待闸船舶数、优先船过闸等待预估**，
以及**3000吨集装箱驳船（满载85柜）在梧州/大利口/紫金村三港的减载柜数**。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 看板页面，双击用浏览器打开即可（无需联网服务器、无需账号） |
| `update_data.py` | 数据采集脚本（纯 Python 标准库，无需 pip 安装任何东西） |
| `data.js` | 采集结果，`index.html` 读取它显示 |
| `history.jsonl` | 每次运行追加一条快照，用于历史趋势曲线 |
| `run_board.bat` | 一键采集（供定时任务调用，日志写入 run.log） |
| `start_lan.bat` / `serve.py` | 起一个局域网静态服务，手机/别的电脑用浏览器访问 |
| `build_standalone.py` | 把页面和数据打成一个自包含的 `西江看板.html`（单文件版） |
| `build_all.py` | 采集 + 打包一条龙（`打包.bat` 就是调它） |
| `打包.bat` | **双击这个**：自动采集最新数据并重新生成单文件版 |
| `西江看板.html` | 单文件版看板：一个文件发给谁都能打开，不依赖 data.js |
| `loading_model.json` | 水位减载公式的拟合参数与观测库（由 `loading_model.py` 训练/更新） |

## 单文件版（发给手机/别人看最方便）

**最简单：双击 `打包.bat`**，它会依次采集数据、重新生成 `西江看板.html`，跑完窗口会停住显示结果。

等价的手工命令：

```powershell
python update_data.py
python build_standalone.py
```

输出的 `西江看板.html`（约 26–29KB）已经把 `data.js` 内联进去，单独一个文件双击就能看，
也能直接发给别人、传网盘、或丢到任意静态托管上。

注意：单文件里**待闸数打开时仍然直连官网实时拉取**，所以是当下的；
**水位/减载/历史曲线**是打包那一刻的快照，要更新就重跑上面两条命令（或双击 `打包.bat`）。

## 在手机或别的电脑上看

### 方式一：局域网（最简单，不用装任何东西）

1. 双击 `start_lan.bat`，窗口里会显示本机地址，例如 `http://192.168.5.127:8123/index.html`
2. 手机连**同一个 Wi-Fi**，浏览器打开这个地址即可
3. 第一次运行如果弹出 Windows 防火墙提示，选「允许访问」

限制：电脑要开着、服务窗口不能关；离开这个 Wi-Fi 就访问不了。

### 方式二：Tailscale（在外面也能看，长期自用推荐）

电脑和手机各装 Tailscale、登录同一账号，手机访问 `http://<电脑的 100.x.x.x>:8123/index.html`（先双击 `start_lan.bat`）。
免费、不暴露公网、地址固定；缺点是两端都要装客户端。

### 方式三：Cloudflare Tunnel（手机不用装 App）

下载 `cloudflared.exe` 放本目录，先 `start_lan.bat`，再另开一个窗口：

```powershell
.\cloudflared.exe tunnel --url http://localhost:8123
```

会给出一个 `https://xxx.trycloudflare.com` 临时地址，任何设备都能打开。
缺点：每次重启地址会变；国内访问速度看运气。

### 方式四：托管到公网静态站（不用一直开电脑）——已经做好了

**公网地址：<https://xijiang-kanban.netlify.app/>**
**代码仓库：<https://github.com/Reallee-1026/xijiang-kanban>**

任何手机、任何网络、任何时间都能直接打开，不需要这台电脑开机，也不需要连同一个 WiFi。
托管在 Netlify（免费计划），由 GitHub 仓库自动部署，不涉及服务器。

- 待闸数：打开页面即直连广西水运官网接口，永远是最新的
- 水位 / 减载 / 历史曲线：用的是提交到仓库那份 `data.js` 的快照，要更新就重新提交一次（见下）

**更新公网版本（每次改了页面或想刷新水位快照）**：

## 两个刷新层次（重要）

| 你要看什么 | 怎么拿最新 |
|---|---|
| **三闸待闸数、今日/昨日已过** | 直接刷新页面即可 —— 页面每次打开都会直连官网公开接口重取 |
| **梧州（四）水位、减载柜数** | 也直接刷新页面即可 —— 水位同样走门户公开接口（逐小时），标题右侧显示“水位·待闸已实时刷新 时:分:秒” |
| **历史曲线（近 20 天水位）** | 也自动 —— 页面直连门户取该站历史逐小时记录，**每天取 08:00 的值**画图（当天没有 08:00 时取最接近的一条，图下会注明） |
| **优先船构成** | 需要跑上面的 `update_data.py`（逐次采集累积出来的，页面自己攒不了） |

所以日常用法：打开或刷新页面，水位、待闸、20 天水位曲线都是当下的；只有优先船构成跟着脚本走（定时任务或手动跑）。

## 数据来源（全部免登录、公开）

1. **梧州（四）西江水位**：广西水运江河海一体化智慧调度「水情气象 · 水文」页 `https://gzfw.gxyhzx.cn/ship-lock/water`，**逐小时**、带流量，珠江基面；取不到时自动退回水利部全国水雨情网 `xxfb.mwr.cn` 的每日 8:00 值。两个来源是同一个站（stcd 80115000）、同一基面，08:00 数值完全一致。
   减载卡片用的就是这一站的水位（与顶部水位卡同源，口径统一）。
2. **待闸船舶数 / 优先船**：广西水运江河海一体化智慧调度·公众服务
   `https://gzfw.gxyhzx.cn/ship-lock/schedule-info` 的公开接口，实时：
   - 待闸 = 锚地待闸 + 靠船墩待闸；另显示官方“新报到 / 预登记”口径。
   - 优先船按官方类型统计：LNG、集装箱、积分排第一、应急抢险、客班轮、危险品等（悬停可看构成）。

## 减载卡片怎么读

梧州水位右侧两张卡，标题都是“3000吨集装箱驳船满载为85个，当前水位需要减载：”

- **左卡**：用当天公布的梧州（四）站水位（珠江基面）自动算三港减载柜数；
- **右卡**：自己输入任意水位，三港数字即时重算，用于推演“水位再降 0.2m 会怎样”。

公式（水位减载公式，`装载模型说明.md` 有完整推导）：

```
x  = max(0, h0 − 梧州（四）站水位)
d  = D · (1 − e^(−a·x^p))      # 该港需减载柜数
减载率 = d / 85
```

参数 `D / a / p / h0` 来自 `loading_model.json`（当前 45 条证据拟合：梧州(李家庄)、大利口、紫金村）。
想更新参数：用 `loading_model.py update <水位> <李家庄柜数> <大利口柜数> <紫金村柜数>` 回填实船数据后重新训练，
再跑一次 `update_data.py`，页面上的参数会自动换成新拟合值（无需改 HTML）。

## 耗时预估怎么读

页面上的预估**是模型计算，不是官方发布**，公式透明、参数可调：

```
普通船等待 = 前方排队艘数 ÷ 单方向日通过能力（艘/天）
优先船等待 = 普通船等待 × 折减系数（默认 0.4）
全程       = 三闸等待之和 + 每闸闸内操作(默认3小时)×3 + 航行时间(默认14小时)
```

- 默认“按待闸合计（锚地＋靠船墩）”口径；大藤峡官方待闸总数含上千艘**预登记（船还没到锚地）**，
  用总数会把预估放得过大，可在页面上切到“按新报到排队”对比。
- “单方向日通过能力”默认值（长洲140、桂平65、大藤峡30）是按近期实际过闸艘数反推的粗值，
  你有调度经验值直接在页面输入框改，数字立即重算。
- 不含船闸故障、停航检修、流量管制；以调度中心实际安排为准
  （长洲 0774-3100771，桂平/大藤峡 0774-3100772）。

## 界面与配色（想自己调样式看这里）

所有样式都写在 `index.html` 顶部那一个 `<style>` 里，**配色集中在开头的 `:root`**：

```
--bg #f4f7fb     页面底色      --panel #ffffff  卡片底色
--txt #1b2637    主要文字      --sub #51637a    次要文字   --dim #8794a8 注释文字
--up #2563eb     上行/主色     --down #e07a1f   下行
--prio #7c5cf0   优先船/合计   --ok #12925f     正常/零减载
--warn #b45309   估算标签      --bad #d92d20    超限/警示
--shadow         卡片阴影（浅色主题下靠它把卡片从底色上"抬"起来）
```

改主色只动这几行，全站跟着变。另外几个常用的：

- **同一行的卡片等高对齐**：`.cols-water` / `.cols-3` 都是 `align-items:stretch`，水位卡首列的 `.kvs` 用 `margin-top:auto` 贴底，所以三张卡的底边是齐的。
- **分区标题的 01 / 02 / 03** 是 CSS 计数器自动生成的，增删板块后会自动重排，不用手改。
- **卡片圆角/内边距**：`--r`（圆角）与 `.card{padding}`。
- **口径说明**默认收起，用的是 `<details class="note">`；想默认展开就在标签里加一个 `open`。
- **折线图**：`lineChart(el, series, labels, opts)`，`opts.area` 控制淡色面积填充，`opts.marks` 控制点上标数值，`opts.rot` 让 X 轴日期按 45° 倾斜且每天都标（水位趋势用的就是它）。
- **水位趋势区**：`.hist-wrap` 是「左列表 + 右图表」两栏（180px + 自适应），列表由 `buildHistory()` 填充、最新一天在最上面；想让列表更宽改 `.hist-wrap{grid-template-columns:180px …}` 里的 180px。
- 手机上（宽度 ≤760px）自动换成单列、水位卡改回竖排、隐藏预估表最右一列，规则在 `<style>` 最后一组 `@media` 里。

## 注意事项

- 趋势曲线需要积累：跑满两天以上自动出现，数据都在 `history.jsonl` 里（可随时用记事本打开）。
- 若某一天采集失败（网络抖动），重新双击 `run_board.bat` 即可；失败不影响已有历史。
- 接口是官方网站自用的公开接口，无对外 SLA，字段或地址若变更，更新 `update_data.py` 里的 URL 即可。
- 数据仅供内部参考，不作为航行、配载、合同依据。
